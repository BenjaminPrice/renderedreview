# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's private vulnerability reporting: open the
repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue,
pull request or discussion for a suspected vulnerability.

Include what you found, how to reproduce it, and the impact you expect. We will acknowledge the
report, keep you updated while we fix it, and credit you in the advisory if you want.

## Supported versions

Rendered Review is developed on `main`; fixes land there. Self-hosted deployments should run a
recent build of `main`.

## Scope

The web app, its packages and the GitHub Action in this repository. What the app protects and how
is described in [docs/security/threat-model.md](docs/security/threat-model.md).

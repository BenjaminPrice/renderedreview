# Alerts

> [!NOTE]
> Useful information that users should know.

> [!tip]
> Helpful advice for doing things better.

> [!IMPORTANT]  
> Key information users need to know.

> [!WARNING]
>
> Urgent info that needs immediate attention.
>
> - with a list

> [!CAUTION]
Lazy continuation of a caution.

## Not alerts

> [!NOTE] Text on the marker line.

> [!FOO]
> Unknown type.

> [!NOTE]

> Text first.
> [!NOTE]
> Marker not on the first line.

> > [!WARNING]
> > Nested blockquote.

- Item

  > [!TIP]
  > Inside a list.
